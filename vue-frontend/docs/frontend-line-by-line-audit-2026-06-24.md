## Review Criteria

- Pages own route-level data assembly and business composition; shell components own layout algorithms; primitives own base controls; business components own scoped styles.
- No old compatibility variables, old frontend schema reads, ordinary `*.styles.css` imports, `:deep()`/`:global()`, business primitive-internal selector overrides, production `any`, stale run logs, or migration-history comments.
- Preserve cohesive interaction owners. Recommend splits only for real owner boundaries, state boundaries, style ownership, lifecycle cleanup, accessibility, or test value.
- Current backend snake_case wire protocol and OpenAI-compatible product naming are current contracts, not old compatibility.
