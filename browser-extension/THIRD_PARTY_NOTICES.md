# Third-party notices

The distributed browser extension contains Saber-Translator project code and project-owned icon assets. It has no runtime package dependency loaded from a CDN or remote service.

The development and packaging workflow uses the following open-source tools. Their license texts are included in each installed package and remain available from their upstream projects:

- TypeScript — Apache License 2.0
- Vite — MIT License
- Vitest — MIT License
- jsdom — MIT License
- Chrome type definitions (`@types/chrome`) — MIT License

These build-time packages are not copied as standalone packages into the release ZIP.
