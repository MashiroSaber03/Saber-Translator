# Saber 漫画翻译浏览器扩展隐私政策

生效日期：2026 年 8 月 31 日

本隐私政策适用于“Saber 漫画翻译”浏览器扩展（以下简称“本扩展”）。本扩展是开源项目 Saber-Translator 的配套组件，用于识别用户当前网页中的漫画图片，在用户确认后调用本机运行的 Saber-Translator 完成翻译，并把译图显示在网页原位置。

## 1. 核心原则

- 本扩展不包含广告，不出售用户数据，不使用用户数据建立广告画像，也不进行与漫画翻译无关的行为分析。
- 本扩展不会把用户数据发送到由 Saber-Translator 项目开发者运营的远程服务器。
- 候选漫画图片在用户确认翻译前不会被发送到 Saber-Translator。
- 本扩展只为提供用户主动使用的网页漫画识别、翻译和结果展示功能处理必要数据。

## 2. 本扩展处理的数据

### 2.1 身份验证信息

本扩展保存用户从本机 Saber-Translator 桌面控制中心复制的配对令牌，以及用户设置的本机服务端口。配对令牌用于证明浏览器扩展有权访问本机 Saber-Translator 接口。

这些信息保存在 `chrome.storage.local` 中，不通过 Chrome 账号同步，也不会发送到项目开发者服务器。

### 2.2 网页浏览信息

为了创建独立的网页漫画翻译任务，本扩展可能处理当前任务页面的：

- 网页地址（URL）；
- 网页标题；
- 网站域名；
- 原始漫画图片地址。

本扩展不会为了广告、用户画像或统计分析而建立用户的浏览历史记录。

### 2.3 网站内容

本扩展可能处理以下网站内容：

- 网页中的候选漫画图片；
- 用户确认需要翻译的漫画图片；
- 翻译后用于替换原图的译图；
- 用于图片识别的必要 DOM 信息，例如节点类型、CSS 类名、父级关系、少量经过限制的属性、元素位置和图片尺寸；
- 用户选择 DOM Agent 时使用的网页标题、经过处理的网页地址及脱敏后的 DOM 摘要。

DOM Agent 摘要不会包含网页 Cookie、表单密码、浏览器认证 Cookie 或完整网页源代码。图片来源属性会在发送给 DOM Agent 前进行限制和脱敏。

### 2.4 扩展偏好设置

本扩展在 `chrome.storage.local` 中按域名保存必要的使用偏好，包括：

- 该网站是否停用扩展；
- 图片识别方式和已保存的站点适配规则；
- 标准翻译或高质量翻译模式；
- 术语表和自动添加术语开关；
- 面板开关状态和界面位置。

这些设置只用于恢复用户自己的扩展配置。

## 3. 数据何时会离开网页

### 3.1 发送到本机 Saber-Translator

用户点击“开始翻译”、使用右键菜单翻译单张图片，或确认同一规则下后续懒加载图片自动加入任务后，本扩展会把完成翻译所需的数据发送到用户设备上运行的 Saber-Translator 本机接口。数据可能包括：

- 用户确认的漫画图片；
- 网页地址、标题和域名；
- 图片顺序、图片来源地址和用于避免重复任务的标识；
- 用户选择的翻译模式和术语相关开关。

本机浏览器扩展接口默认关闭，只有用户在 Saber-Translator 中主动启用并完成配对后才能访问。接口使用配对令牌验证请求，译图访问地址具有时效性签名。

### 3.2 用户自行配置的第三方服务商

Saber-Translator 支持本地模型，也允许用户自行配置在线 OCR、翻译、视觉模型或其他 AI 服务商。若用户选择在线服务，Saber-Translator 可能按照用户自己的设置，把完成所选功能所必需的图片、OCR 文本、翻译文本或 DOM Agent 摘要发送给对应服务商。

第三方服务的处理范围、保存时间和安全措施由用户选择的服务商及其隐私政策决定。本扩展不会在用户未配置相关服务的情况下自行选择第三方服务商，也不会把配对令牌发送给这些服务商。用户可以在 Saber-Translator 中选择完全本地的模型，以避免向第三方发送翻译内容。

## 4. 数据保存与删除

### 4.1 浏览器本地数据

配对令牌、端口和按域名设置保存在浏览器本地，直到用户执行下列任一操作：

- 在浏览器中卸载本扩展；
- 清除本扩展的存储数据；
- 修改或删除相关站点设置；
- 在 Saber-Translator 中重新生成配对令牌，使旧令牌立即失效。

### 4.2 Saber-Translator 本机数据

未导入书架的网页漫画临时任务通常在最后一次活动 24 小时后过期，并在没有运行中任务继续使用时由 Saber-Translator 清理。用户把任务导入书架后，书籍、章节、原图、译图和相关翻译数据会保留在用户自己的 Saber-Translator 数据目录中，直到用户通过 Saber-Translator 删除相关内容或清理本地数据。

所有上述数据都位于用户控制的设备和数据目录中，项目开发者无法远程访问或替用户删除这些本地数据。

## 5. 权限用途

- `storage`：在浏览器本地保存配对信息、站点适配规则和界面偏好。
- `contextMenus`：提供用户主动触发的“使用 Saber 翻译此图片”右键菜单。
- `http://*/*` 和 `https://*/*` 主机权限：在用户访问的漫画网站中识别候选图片、读取用户确认的图片，并把译图替换回原位置；同时支持不同域名和跨域来源的漫画图片。
- Content Script：在网页中显示扩展悬浮按钮、候选图片、任务进度和译图结果。

本扩展不下载或执行远程 JavaScript、WebAssembly 或其他远程代码。扩展的可执行逻辑全部包含在发布安装包中；本机接口或模型服务返回的图片、文字、节点 ID 和结构化结果均作为数据处理，不会作为代码执行。

## 6. 数据共享与禁止用途

除用户为了完成所选翻译功能而自行配置的服务商外，本扩展不会向第三方出售、出租或共享用户数据。本扩展不会：

- 将用户数据用于与网页漫画翻译这一单一用途无关的目的；
- 将用户数据用于个性化广告、再营销或兴趣画像；
- 将用户数据用于确定信用度、贷款资格或金融决策；
- 允许项目开发者或其他人员人工阅读用户的漫画内容；
- 收集健康信息、付款信息、精确位置或个人通讯用于任何独立目的。

## 7. 安全措施

本扩展和 Saber-Translator 采用以下措施降低本机数据被未授权访问的风险：

- 浏览器扩展接口默认关闭，并仅用于本地运行配置；
- 接口请求需要用户生成的高强度配对令牌；
- 令牌比较和译图临时访问签名使用安全的消息认证机制；
- DOM Agent 只接受字段受限、数量受限且经过脱敏的节点摘要；
- 扩展页面采用 Manifest V3 内容安全策略，不执行远程代码。

用户应妥善保管配对令牌，不要把令牌发送给他人。怀疑令牌泄露时，应立即在 Saber-Translator 中重新生成令牌。

## 8. 用户选择与控制

用户可以随时：

- 在扩展面板中停止发现图片或取消当前任务；
- 对指定网站停用扩展，或删除已保存的站点适配规则；
- 在浏览器中清除扩展数据或卸载扩展；
- 在 Saber-Translator 中关闭浏览器扩展接口或重新生成配对令牌；
- 选择本地模型或更换、删除在线服务商配置；
- 删除临时任务、书架内容或整个 Saber-Translator 本地数据目录。

## 9. 儿童隐私

本扩展不是专门面向儿童设计的服务，也不会有意收集儿童的个人身份信息。用户应确保其翻译和访问的内容符合所在地区的法律及网站使用规则。

## 10. Chrome Web Store Limited Use 声明

本扩展对从浏览器获得的用户数据的使用遵守 [Chrome Web Store User Data Policy 的 Limited Use 要求](https://developer.chrome.com/docs/webstore/program-policies/limited-use/)。用户数据只用于提供或改进本扩展明确展示的网页漫画识别、翻译和译图展示功能。

Use of user data by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## 11. 政策变更

如果本扩展的数据处理方式发生实质变化，本政策将同步更新生效日期和相关说明。涉及新的数据类型、用途或第三方传输方式时，将在扩展界面或商店详情中提供适当说明，并在适用情况下取得用户同意。
