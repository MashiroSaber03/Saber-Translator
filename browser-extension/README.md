# Saber 漫画翻译浏览器扩展

该扩展调用本机运行的 Saber-Translator，把网页漫画图片逐张送入现有翻译流程，并在原位置显示译图。当前支持桌面版 Chrome 和 Edge，可通过浏览器扩展商店或本地 ZIP 包分发。数据处理方式见[隐私政策](PRIVACY.md)。

## 安装

1. 解压 `saber-translator-browser-extension-v1.1.0.zip`。ZIP 不能直接拖入浏览器安装。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚解压且直接包含 `manifest.json` 的目录。
4. 更新时，先关闭正在使用扩展的漫画页，把新 ZIP 解压并覆盖原扩展目录，再在扩展管理页点击该扩展的“重新加载”。这样会保留配对令牌和按域名设置；若改用新目录重新安装，则需要重新配对。
5. 卸载时，在扩展管理页点击“移除”；若不再使用，也可在 Saber GUI 中关闭浏览器扩展连接。

## 配对与使用

1. 启动 Saber-Translator，在 GUI 中打开“允许浏览器扩展连接”。复制配对令牌；若修改了 Saber 端口，也记下该端口。
2. 点击浏览器工具栏里的粉色 Saber 图标，粘贴令牌和端口，保存并测试连接。
3. 打开漫画页面，点击右下角粉色悬浮按钮，选择识别方式并确认候选图片。扩展在用户确认前不会上传图片。
4. 也可以右键单张图片，选择“使用 Saber 翻译此图片”。
5. 面板支持查看进度、全局或单页切换原图/译图、单页重翻/重试、停止继续发现和取消任务；任务结束后，可以把当前独立章节新建为一本书，或追加到已有书籍末尾。悬浮按钮和面板标题栏都可以拖动调整位置。每次展开时，面板贴近悬浮按钮并自动避开屏幕边缘；手动拖动面板只影响本次展开，收起后再次打开仍跟随按钮。

插件仅独立保存文本样式（字体排版、颜色与填充、描边）；OCR、文本检测、翻译服务、模型、密钥、提示词及并行参数沿用翻译器已有配置，无需在插件中重新填写。可在网页悬浮窗内的“配置”页签或翻译页面“设置 → 浏览器插件”编辑同一套插件文本样式，不影响翻译器的“文本默认值”。网页识别助手作为可选专用功能单独配置，只用于 DOM Agent 图片识别，不参与翻译。两处均在修改后自动保存，Web 关闭设置时会保存尚未提交的修改；仅保存失败时提供重试或放弃修改并重新读取。开始网页翻译时读取翻译器服务配置和插件文本样式，同一次漫画的后续图片与重试保持该配置；修改后重新开始翻译生效。“任务中心”仍操作同一后端任务队列。

配对令牌等同于本机扩展接口的访问密钥，请勿发送给他人；怀疑泄露时可在 Saber GUI 中重新生成，旧令牌会立即失效。

本版本增加了浏览器会话存储表并更新数据结构版本。若启动器提示现有 `data-v2` 版本不兼容，请先完整备份该目录，再按提示手工清理；Saber 不会自动删除或迁移旧数据。

## 识别方式

- “站点适配 / 通用”：优先使用内置站点规则；未知站点使用图片尺寸与 DOM 结构筛选。
- “DOM Agent”：只把裁剪、脱敏后的图片节点摘要发送给插件“配置”中的网页识别助手模型，候选结果仍需人工确认。
- “点选同类图片”：点击一张漫画图，按相似 DOM 结构选出同类图片。

确认后，新出现并匹配相同规则的懒加载图片会自动加入当前会话。可在任意域名停用扩展，再从工具栏弹窗重新启用。

网页翻译即用即抛：刷新、关闭标签页或离开当前漫画页面后，扩展会取消该页面尚未完成的任务，待运行中的任务停止使用图片后清理临时数据。重新打开页面不会恢复之前的任务。切换标签页、窗口失焦、收起悬浮面板不属于退出，不会清理。需要保留结果时，请在退出前主动导入书架；已导入的书籍不会被临时清理删除。

浏览器异常退出、断连或标签被浏览器丢弃时，后端会在页面存活租约失效后兜底取消和清理。正常打开的页面由扩展后台维持租约，不依赖用户持续点击。

图片已上传但翻译服务配置不完整时，请在翻译器对应设置中修正，再在插件点击“重试启动”，无需重新上传。任务中心支持运行中暂停、恢复、继续中断任务、取消和失败重试；全局队列暂停/恢复会同时影响 GUI、Web 和插件提交的任务。

网站改版导致已保存规则失效时，可在悬浮面板“翻译 → 页面操作”中点击“删除已保存适配”。扩展只会删除当前网站的识别规则，并立即按当前识别方式重新检测；翻译模式、术语开关和面板位置会保留。

## 已知边界

- 不处理跨域 iframe、DRM 资源和浏览器禁止读取的受污染 Canvas。
- 需要登录或 Cloudflare 验证的图片，必须先在当前站点完成验证；个别站点仍可能阻止扩展下载。
- 条漫切片按独立图片翻译，不保证识别跨越两张切片的文字，也不会自动拼接图片。
- MangaDex 等站点的登录或访问策略可能阻止自动化测试，需在真实登录态中人工确认。

## 悬浮窗结构

悬浮窗使用插件自己的粉色主题和控件，翻译、配置、任务共用一个标题栏与三个固定页签，支持浅色／深色主题、键盘操作和小窗口布局，不加载翻译器 Web 的页面组件或样式。

- `src/ui.ts`：网页宿主，只负责悬浮按钮、拖动位置、图片选取遮罩和消息转发。
- `src/PanelApp.vue`、`src/studio/`：同一个扩展文档内的三个视图和插件专属控件。
- `src/panel.css`、`src/hostStyles.ts`：插件内部样式与网页宿主样式。
- `vue-frontend/src/composables/useBrowserExtensionSettings.ts`：两边共用配置读取和自动保存逻辑，不包含 UI 或样式。
- 原有 `content.ts`、`background.ts`：继续处理识别、图片传输、会话和后端通信。类型、配置校验和任务名称等纯逻辑继续共享。

页面退出即清理会话的规则保持不变；收起窗口只暂停任务列表刷新，不会取消翻译。配置修改后自动保存，收起再打开保留当前页签。

## 开发与打包

需要 Node.js 20.19+ 或 22.12+：

```powershell
npm ci
npm test
npm run typecheck
npm run package
```

发布物生成在 `release/`，每个 ZIP 都带有对应的 SHA-256 文件：

- `saber-translator-browser-extension-v<version>.zip`：开发者模式安装包，保留固定扩展 ID。
- `saber-translator-chrome-web-store-v<version>.zip`：Chrome Web Store 上传包。
- `saber-translator-edge-addons-v<version>.zip`：Microsoft Edge Add-ons 上传包。

两个商店包使用同一份构建结果并移除仅供开发期固定 ID 的 `key`，不需要维护两套扩展源码。
