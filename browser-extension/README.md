# Saber 漫画翻译浏览器扩展

该扩展调用本机运行的 Saber-Translator，把网页漫画图片逐张送入现有翻译流程，并在原位置显示译图。首版支持桌面版 Chrome 和 Edge，以 ZIP 包分发，不依赖扩展商店。

## 安装

1. 解压 `saber-translator-browser-extension-v1.0.0.zip`。ZIP 不能直接拖入浏览器安装。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚解压且直接包含 `manifest.json` 的目录。
4. 更新时，先关闭正在使用扩展的漫画页，把新 ZIP 解压并覆盖原扩展目录，再在扩展管理页点击该扩展的“重新加载”。这样会保留配对令牌和按域名设置；若改用新目录重新安装，则需要重新配对。
5. 卸载时，在扩展管理页点击“移除”；若不再使用，也可在 Saber GUI 中关闭浏览器扩展连接。

## 配对与使用

1. 启动 Saber-Translator，在 GUI 中打开“允许浏览器扩展连接”。复制配对令牌；若修改了 Saber 端口，也记下该端口。
2. 点击浏览器工具栏里的粉色 Saber 图标，粘贴令牌和端口，保存并测试连接。
3. 打开漫画页面，点击右下角粉色悬浮按钮，选择识别方式并确认候选图片。扩展在用户确认前不会上传图片。
4. 也可以右键单张图片，选择“使用 Saber 翻译此图片”。
5. 面板支持查看进度、全局或单页切换原图/译图、单页重翻/重试、停止继续发现和取消任务；任务结束后，可以把当前独立章节新建为一本书，或追加到已有书籍末尾。悬浮按钮和面板标题栏都可以拖动调整位置。

OCR、文本检测、翻译器、修复器、字体和排版均使用 Saber 当前全局设置；是否并行及并发数量直接遵循翻译页面“设置 → 更多”中的并行翻译设置。扩展只保存配对信息和按域名设置，不包含独立翻译引擎。

配对令牌等同于本机扩展接口的访问密钥，请勿发送给他人；怀疑泄露时可在 Saber GUI 中重新生成，旧令牌会立即失效。

本版本增加了浏览器会话存储表并更新数据结构版本。若启动器提示现有 `data-v2` 版本不兼容，请先完整备份该目录，再按提示手工清理；Saber 不会自动删除或迁移旧数据。

## 识别方式

- “站点适配 / 通用”：优先使用内置站点规则；未知站点使用图片尺寸与 DOM 结构筛选。
- “DOM Agent”：只把裁剪、脱敏后的图片节点摘要发送给在 Saber“网页漫画”页单独配置的模型，候选结果仍需人工确认。
- “点选同类图片”：点击一张漫画图，按相似 DOM 结构选出同类图片。

确认后，新出现并匹配相同规则的懒加载图片会自动加入当前会话。可在任意域名停用扩展，再从工具栏弹窗重新启用。

网站改版导致已保存规则失效时，可在悬浮面板的“翻译设置”中点击“删除已保存适配”。扩展只会删除当前网站的识别规则，并立即按当前识别方式重新检测；翻译模式、术语开关和面板位置会保留。

## 已知边界

- 不处理跨域 iframe、DRM 资源和浏览器禁止读取的受污染 Canvas。
- 需要登录或 Cloudflare 验证的图片，必须先在当前站点完成验证；个别站点仍可能阻止扩展下载。
- 条漫切片按独立图片翻译，不保证识别跨越两张切片的文字，也不会自动拼接图片。
- MangaDex 等站点的登录或访问策略可能阻止自动化测试，需在真实登录态中人工确认。

## 开发与打包

需要 Node.js 20.19+ 或 22.12+：

```powershell
npm ci
npm test
npm run typecheck
npm run package
```

发布物生成在 `release/`，包含 ZIP 和对应的 SHA-256 文件。
